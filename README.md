# 百合日历

**中文简介：** 用 HTML、CSS 和 JavaScript 构建的静态日历，固定展示全年 366 个日期。

**English overview:** A static HTML, CSS, and JavaScript calendar that displays all 366 dates of the year.

## 使用 / Usage

静态站点入口为 `index.html`，日期数据位于 `data/`。本地服务需要 Node.js 22+。

The static site starts at `index.html`, with date data in `data/`. The local server requires Node.js 22+.

```text
npm run dev
```
